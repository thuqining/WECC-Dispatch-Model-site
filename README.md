# WECC Dispatch Model -- results dashboard (2025)

Public results dashboard of a day-ahead / real-time market model of CAISO and the rest of WECC, run over all 53 weeks
of 2025. Results only; the model code is in a private repository.

**Headline metric: CAISO's three DLAPs** (DLAP_PGAE, DLAP_SCE, DLAP_SDGE -- CAISO's published prices). Prices for the
other areas are the model's own shadow prices compared with CAISO's WEIM ELAP prices; they are indicative only.

Transmission network detail (WECC base-case buses and lines) is not published; the map is schematic.
